# Experiment Log

Experiment definitions are versioned in `configs/experiments.yaml`; machine-readable results are stored in `artifacts/reports/experiments.json` and `evaluation.json`.

The matrix covers global popularity, category popularity, content, collaborative, hybrid without mission, mission-aware hybrid, optimized basket, and controlled exposure. Model weights are selected on validation NDCG@10. Test-set comparisons and ablation are generated by `scripts/evaluate.py`. The included A/B result is a simulation only and must never be cited as causal production lift.
