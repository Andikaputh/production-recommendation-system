# Dataset Card : rasa-synth-1.0.0

This dataset is entirely synthetic and generated by `scripts/generate_data.py` with seed 42. It contains 10 categories, 30 merchants, 600 products, 500 pseudonymous profiles, and 52,174 events across a 120-day simulation window.

## Intended use

Intended uses are development, reproducibility, offline evaluation, API demos, and portfolio review. It is not suitable for training a commercial system, estimating demand, evaluating real merchants, or drawing conclusions about human behavior.

## Splitting and leakage

Interactions are ordered by time for each user. Training, validation, and test splits are separate: validation selects weights, while test only reports final results. Quality checks cover referential integrity, enums, missing values, duplicates, timestamps, temporal leakage, and event isolation.

## License and limitations

Synthetic data is released under CC BY 4.0. Product and merchant names are fictional. Simulation bias comes from generator rules; exposure, rating, category, and preference distributions do not represent a real marketplace. Manifest checksums are available in `data/raw/dataset_manifest.json`.
